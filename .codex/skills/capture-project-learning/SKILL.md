# 沉淀项目协作经验

读取根 `AGENTS.md`、`docs/collaboration/knowledge-maintenance.md` 和当前主题的索引。
这些路径均相对于项目根目录；从当前工作目录向上定位根目录，必要时用 Git 确认。

## 筛选与路由

- 从当前任务中提取后续可能复用的内容，不保存完整聊天或机械操作清单。
- 明确区分用户原话所确认的偏好、直接验证的事实、历史经验和待核实推断。
- 检索现有文档，优先修订主要来源；按维护规则选择偏好、研究、决策或 Skill。
- 只有具有可执行步骤、输入、验证和结束条件的成熟流程才形成新 Skill。
- 单次临时指示不升级为长期偏好；有影响的重要歧义需要向用户确认，其他候选可暂不记录。

## 执行与验证

- 维护范围限于当前项目和相关主题，保留已有暂存状态。
- 给研究事实保留版本及代码或官方资料依据；必要时标记待核实。
- 新增页面更新对应索引；修复当前涉及的断链和过时内容。
- Skill 引用已有知识，避免重复；新增脚本实际运行验证。可用时使用 skill-creator 的结构校验器。
- 检查 diff、相对链接及根 `AGENTS.md` 的简洁程度；没有复用价值时不创建文件。

完成条件：相关知识有明确的主要来源、可发现入口和依据，内容不超出已验证范围。
最终简述本次有意义的更新及路径；没有新增内容无需专门汇报“未沉淀”。
用户已授权完整知识更新按根 `AGENTS.md` 的规则自动提交与推送；没有实际改动不创建空提交，失败不重试或修复。
此授权不包含执行文档中描述的其他外部发布或消息发送操作。
