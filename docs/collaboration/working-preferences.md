# 用户工作偏好

适用范围：本项目。最后确认：2026-11-14（Asia/Shanghai）。
仅记录用户明确表达或明确接受的偏好；后续具体指示可以覆盖这里的默认值。

| 偏好 | 执行方式 | 来源 |
| --- | --- | --- |
| 根指引简明干练 | `AGENTS.md` 约不超过 200 行，非硬上限；细节放 `docs/` | 用户明确要求 |
| 主动沉淀协作成果 | 识别经验、方法、工作偏好和技能，符合维护规则时直接更新 | 用户明确要求并授权实施 |
| 项目内保存可复用资料 | 项目知识放 `docs/`，项目 Skills 放 `.codex/skills/` | 用户接受方案并要求实施 |
| 对照实际产物理解项目 | 结合官方 VS Code 插件包和 Codex 源码研究，保留版本及证据 | 用户要求下载解压并对照理解 |
| 重视人与 Agent 的协作方法 | 研究仓库时关注可迁移到日常工作的实践，并区分事实与建议 | 用户明确说明研究目的 |

不要据此推断用户对其他项目的全局偏好，也不要把本次采用的版本、分支或某次验证范围记为永久偏好。
如果用户纠正一条偏好，修订原条目并更新确认日期；存在重要歧义时再询问。
